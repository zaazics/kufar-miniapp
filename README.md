# 📱 Kufar Парсер — Telegram Mini App

Интерактивный интерфейс для поиска объявлений на Kufar.by.

## Функции

- 🔍 Поиск по категориям
- 🏷️ Фильтр по цене и городу
- ⭐ Сохранение в избранное
- 📄 Пагинация
- 🏆 Определение лучших предложений

## Установка

1. Загрузите файлы в репозиторий
2. Включите GitHub Pages
3. Укажите ссылку в боте

## Технологии

- HTML5 / CSS3
- Vanilla JS
- Telegram Web App API
- GitHub Pages
